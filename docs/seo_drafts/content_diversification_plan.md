## 战略原则

**"Hub-and-spoke" 内容模型**：每个旗舰是一个内容枢纽（Hub，2500-4000 字，targeting 高 SV 短尾），围绕它建 4-5 篇长尾文（Spoke，800-1500 字，targeting 长尾问句词）。Spoke 内链向上指 Hub，Hub 顶部"目录"指 Spokes。Google 看到的是一个**主题集群**而非孤立文章 → 整体权重升 + 一个 Hub 抗跌。

**Iris 文风一致性**（强制）：每篇必须有时间锚开场、Key Stats 表、em-dash、括号旁白、AFFiNE/30x PH/Analook 三选一的真实经验锚点。

**双站协议**：每篇 GitHub _posts → 同步发 dev.to/iris1031（dev.to canonical 指向 dev.to 自身，避免重复内容惩罚）。Cross-link 主站的 analook.com /compare/ 或 /docs/mcp 在 1-2 处编辑式插入（不堆积）。
