## 0 付费的根因分析（基于上面数据）

| 假设 | 数据是否支持 |
|---|---|
| **A. 没人来** | ❌ 反驳。78 注册 +30天 35 新增，组合 SEO 起效 |
| **B. 报告质量不行** | ❌ 反驳。激活率 50% 说明拿到一份就觉得值 |
| **C. 没人重度使用** | ✅ 支持。top 5 用户都 ≤3 报告，没人接近 free tier 上限 |
| **D. 单 $5/report 太便宜，导致 Pro 没动力** | ⚠️ 部分。$5 等于 6 份 = $30 几乎等价 Pro $29，理性用户不升 Pro |
| **E. Pro $29/mo 价值主张不清** | ✅ 支持。30 报告/月 = 重度用户才需要，但没人是重度用户 |
| **F. Team $99/mo 没有 trigger** | ✅ 支持。没看到任何团队场景 demo |

**核心问题**：当前定价结构假设的是「先 free → 用完升 Pro」漏斗，但实际用户行为是「试一次 → 散」。你需要：

1. **更激进地把 free 限制收紧**（已经从 3/月 → 2/月做了一步），让 light user 更快撞上限
2. **加 "single report $5" 路径的曝光**（top 5 高活用户里如果每月跑 2 次，$5 单卖 = $10，比 free 多收）
3. **写一个 "Pro 用户能做什么 Free 做不到的" feature wall**，比如 PDF 报告 / 历史对比 / 团队共享 —— 现在 Pro 仅仅是 quota 更大
4. **针对 AI/SaaS 出海创始人写一个 "30 个常用竞品分析模板"**，订阅才能用 —— 把 Pro 从 "30 个 quota" 变成 "30 个高价值场景"
